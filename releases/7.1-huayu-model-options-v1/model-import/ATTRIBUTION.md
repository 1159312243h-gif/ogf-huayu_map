The downloaded GLB includes the same author, source and license notices. They
remain embedded in the prepared file. The leaf material was changed from alpha
blending to alpha cutout (threshold 0.3) to participate in the map's shared depth
buffer. Geometry and textures are unchanged. The map uses the complete birch-1
subtree (trunk and leaves, 3,414 triangles), rather than planting all four trees
at each mapped tree position. Orientation, bounds and height are fitted by the
existing importer. No endorsement by the original author is implied.

At runtime, the leaf color texture receives coverage-preserving mipmaps for
alpha cutout. Downsampling uses alpha-weighted linear colors and adjusts each
smaller level independently, so distant leaves do not disappear or darken at
transparent edges. The original GLB, source texture, level-zero pixels and
geometry are retained; these rendering mipmaps are generated once and shared
by all tree instances. No model dimensions or mapped tree positions change.
