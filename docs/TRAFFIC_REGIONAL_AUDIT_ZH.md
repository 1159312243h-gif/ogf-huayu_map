## 通用修复与保留限制

- 城市、省、国家统一读取允许汽车通行的道路类别，包含住宅、生活与服务道路；内部路仍只作首末接入。缺路或不连通不制造连接。
- 人口点按粗到细建立层级，零剩余父点仍约束子点范围；城市、村庄及建筑人口不重复相加。明确行政级别、place:hx优先；capital=yes/2/3/4表示政府驻地，不是整国或整省人口范围。没有华域标签的国外八级城市关系仍可使用其实际admin_centre人口。
- 面板列出地名点总数／有效人口标签数，以及已知、已接路和未接路人数。未标地名可以通过已有上级总量分配位置，不额外新增人口；上级总量也未知时只能报告已知部分。
- 单响应32 MiB／60000对象、路网40000条／35万节点、图16万有向段及12°跨度限制保留。整国超限仍须分区域，不能用截断输入假称全国计算完成。
- 源建筑面只有内环时不擅自改成外环，错误明确列出对象ID；失败保留已有完整模拟。汤海共和国本轮即命中此限制，原始对象为[关系566910](https://opengeofiction.net/relation/566910)。
- 原建筑、颜色、屋顶、日照、导航、停车及两分钟／五分钟／三小时更新周期保持原规则。

```powershell
node scripts/audit-traffic-regions.mjs 305055 307794 309351 28660
node scripts/audit-traffic-regions.mjs --replay 305055 307794
node scripts/audit-traffic-regions.mjs --refresh-population 305055
```
