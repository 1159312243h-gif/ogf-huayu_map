# 本地模型导入

已取得并核验 10 款可替换文件：白桦、松树、单株灌木、雏菊、木亭、候车亭、喷泉、单段栅栏、围墙及轻量平遥城墙段。六类结构物已接入地图适配，与植被及建筑共用深度遮挡。用户已取消地铁出入口替代方案，相应分类与两款台北候选不再提供。在“设置 → 模型替代方案”选择即可准备已有文件，无需重新上传或登录；经典模型仍为默认，既有选择不会被批量导入改写。下拉选项只显示模型名称，文件与应用状态保留在下方说明中。

白桦首次选择才按需加载约 1.9 MB 的同源文件并校验 SHA-256。使用完整单棵树干与树叶（3414 三角面），不会把原文件的四棵树整组重复布置。叶片透明裁切适配共享深度；全部已导入文件的作者、CC BY 4.0 许可和修改说明保存在 [署名文件](../site/model-import/ATTRIBUTION.md)，来源信息也保留在 GLB 中。

内置白桦的叶片使用保留透明裁切覆盖率的多级缩小贴图，缩小时不再因普通采样把树冠丢成散点。缩小颜色按叶片透明度加权，并在线性空间计算，减少暗边；透明空隙、原始贴图及近景细节保留。只在该模型解析时生成一次约 1.33 MiB 的共享贴图，不随缩放拖拽重算、不增加实例数量、尺寸或模型面数；其他本机模型保持自身材质，模拟卫星仍沿用平面表达。

在地图左侧的“设置”中，进入“模型替代方案”：

1. 选择对应类型与候选，再点击上传图标。
2. 选择已合法取得的 `.glb` 文件。ZIP、FBX、OBJ、PMX 和分离贴图的 glTF 需先转换为内嵌贴图的 GLB。
3. 检查实际模型预览，可拖动旋转、滚轮缩放；必要时调整朝上轴、旋转角度，或从模型组中选择单个部件。
4. 确认文件来源与本机使用授权，再保存。选择“沿用现有模型”即可暂停替换；恢复默认不会删除已导入文件，垃圾桶图标可确认移除本地文件。

植被替换支持阔叶树、明确针叶标签的松树、花簇和灌木，复用当前要素的位置、实际高度、密度与避让结果。松树不依据名称推断，旧缓存没有叶型信息时使用通用树木表达。模拟卫星不使用外部立体模型。

亭子、候车亭和喷泉按真实面轮廓、孔洞与方向适配，点状亭子沿用已有道路避让范围，点状喷泉读取高度和直径标签。只有明确类型标签参与替换，名称含“亭”或“喷泉”不新增模型。高度、底部高度以及有效建筑和屋顶颜色标签保留。完整实时建筑接管后才替换对应面状亭子及候车亭，避免重复叠画。

栅栏、围墙和城墙沿现有墙线及实际宽度分段，透视中使用共享深度模型，俯视保留既有线面表达。墙段两端沿已有地形坡面调整，保持标注的垂直高度。栅栏只用完整单段（300 面），不重复整组。城墙使用裁出、减面、校正面朝向并封闭切端的墙段（4836 面，约 889 KiB），保留扫描砖墙、步道、垛口及贴图，剔除周边街道、车辆、草地与建筑。城门不替换成普通墙段。

轮廓内无法完整适配、整条墙超出预算或者加载失败时，保留完整原模型，不隐藏一半、越界放置或重复绘制。

仅接受静态、未使用不支持压缩扩展的 glTF 2.0 GLB。单文件最多 24 MiB、24 个网格和 10 万三角面；最多 8 张最长边不超过 2048 像素的 PNG/JPEG/WebP 贴图。过大的扫描、树木组和场景建议先选择单体、减少面数并压缩贴图。模型不能请求外部贴图或执行脚本。

地图替换进一步限制为单体不超过 2 万三角面、单批最多 256 实例及 40 万三角面；预算外继续显示原模型。选择“自然树冠”时，未替换部分继续使用自然树冠，否则沿用经典模型。

文件保存在当前浏览器、当前站点来源的独立 IndexedDB 中，总容量最多 128 MiB。不上传服务器，不提交到 GitHub，也不影响地形和建筑的三小时更新。刷新与同一来源再次打开可复用；更换浏览器、域名或本地端口不能直接共享这份存储，清理站点数据也会移除文件。

上述浏览器存储范围仅指自行导入的文件。已核验的 10 款内置文件随站点提供，浏览器缓存可复用，IndexedDB 不可用时也可选择。自行导入的同候选模型优先于内置版本，移除本机文件后恢复内置候选；选择“沿用现有模型”或恢复默认可停用替换，不修改其他偏好。加载或完整性校验失败时仍使用原模型。本地完成不表示当前版本已上传 GitHub 或部署 Cloudflare。

注册或登录 Sketchfab、取得文件与许可仍由用户完成。页面不会索要账户密码，不购买模型、不绕过下载限制。模型作者、候选来源和许可随文件记录保留；公开部署模型文件必须另行核验再分发许可，不能把本机使用确认当作公开发布授权。

模型检查使用实际下载文件、文件哈希及浏览器预览；自建几何仍用于失败回退、权限和接口边界检查。`scripts/prepare-birch-model.mjs` 可从已核验的原始白桦文件复现内置版本；`scripts/prepare-model-candidates.mjs` 可复现灌木、候车亭和喷泉的兼容版本。两者均不覆盖原件、不在线抓取模型，不放宽导入预算。

## 批量取得剩余候选

`node scripts/download-model-candidates.mjs 54345` 启动仅监听 `127.0.0.1` 的本地批量工具，打开 `http://127.0.0.1:54345/` 后在本机输入一次 Sketchfab API token。令牌只用于当前进程向官方 API 发起下载认证，不保存到磁盘、日志、浏览器存储或模型文件；不读取浏览器登录资料。下载源来自官方 `/v3/models/{uid}/download`，只接受官方返回的 HTTPS Sketchfab、Amazon AWS 或 CloudFront 文件地址，认证头不发送给文件下载地址。

每项先检查模型 ID、当前下载状态及 CC BY 4.0 许可，再下载完整 GLB。原件、SHA-256、来源记录和处理报告保存在被 Git 忽略的 `.data-update/model-downloads/`。重复批次可复用原件；单项失败不覆盖其他成功项。普通模型继续通过现有导入预算和同版加载器检查，生成实际预览，再登记到 `site/model-import/bundled-candidates.json` 并更新公开署名。登记的文件按需加载，现有偏好与经典默认不自动改变，本机自行导入的文件优先。模型组需核对完整单株和 LOD，不能将整组重复布置。

2026-10-13 批次实际完成：9 款候选已下载、检查并登记，连同既有白桦共 10 款文件；平遥城墙原件（约 107 MiB、338 万面）保留用于离线制备，现场只加载轻量墙段。两款未开放下载的台北入口随后按用户要求从候选目录移除，后续批次不再请求它们。批量工具不购买模型、不绕过限制、不执行三小时数据重建或自动发布。

灌木只提取完整 `Bush_medium_001_LOD0` 的木质枝干与叶片（222 面），保留原始祖先变换与六张引用贴图，移除其他株、LOD、地面和人物参考；叶片改用 0.3 透明裁切参与深度遮挡。候车亭去掉四个辅助线网格，保留全部六个三角面网格、支架与玻璃。喷泉五个零镜面反射的旧式材质转换为金属度/粗糙度及显式零镜面反射参数，保留原贴图、几何、透明水体及变换。原件及哈希均保留，转换仅针对已经核验的原件哈希；原件变更时停止并重新检查。

`node scripts/download-model-candidates.mjs --offline` 使用已有来源记录和原件哈希重新转换、浏览器校验及登记，不索要 token、不联网下载。成功项独立保留；本地批量页面会显示最近完成报告，而不是再次显示待下载。

城墙段由 `scripts/prepare-city-wall-model.mjs` 从固定原件哈希及固定裁剪范围复现。离线工具使用 `meshoptimizer@0.25.0`；维护者可运行 `pnpm --dir .data-update/model-tools add meshoptimizer@0.25.0 --ignore-scripts` 安装。浏览器和三小时数据工作流不依赖这个减面工具。源码、减面说明、原件哈希和公开署名保留；重新抓取地图数据不会重复下载或减面模型。
