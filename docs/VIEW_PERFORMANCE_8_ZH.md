# 8.0 交通与地形性能验证

发布构建：`8.0-view-performance-v1`，2026-10-26。用户已确认上传 GitHub 并部署 Cloudflare，实际完成状态以发布工作流与线上检查为准。保留此前已验证的店名识别修改及全部历史发布文件。

## 修改范围

- 换乘规则每次应用中复用线路名称归一化和每条规则的匹配结果；同批站点显示复用同名归一化。复用只在本次调用内，服务规则、线路、站点更新后重新匹配；前端、实时后台收集与定时快照继续使用原共用函数。
- 检查样式就绪、主题和图层类别时读取已有样式状态及公开图层顺序／对象，避免反复序列化整份实时 GeoJSON 和所有样式表达式。只读分类摘要，不缓存旧顺序，保留完整样式读取及旧接口回退；底图销毁后的处理仍由既有回归验证。
- 结构物先筛掉无关数据源事件，再检查地图状态。地形忽略未完整的数据源通知后继续沿用原遮罩合并与刷新规则。
- 地形按原选择、裁切及可见区间算法准备绘制任务；没有可见三角形时不读写 GPU。完整网格、旧版无索引网格、跨视野三角形、材质、纹理、遮罩、层级回退及 GPU 状态恢复不变；有绘制内容时仍使用原着色器与原顶点。
- 包版本为 `8.0.0`，界面版本为 `8.0`，入口及本次修改的模型脚本使用新的内容版本参数；未改变缓存新鲜度或清空用户缓存。

本次优化没有重新抓取或重建交通／地形快照，没有改变两分钟模型更新、三小时完整重建及五分钟发布检查。发布前合并远端 `ee29050` 所含的完整交通／地形自动更新；远端品牌目录尚不包含店名识别，故继续采用本地已验证的完整名称识别目录，保留其 `2026-10-26T04:30:39.679Z` 生成时间和 `2026-10-26T04:02:53Z` 最早源时间，不拼接半包或伪造刷新时间。导航、账号、下载、品牌、桥梁默认关闭、真实双轨和人工换乘规则继续保留。

## 可复核的结果

使用同一份真实交通快照、相同检查脚本，分别执行修改前后的显示准备。四次平均耗时为 **323.7 ms → 168.8 ms**，约减少 **48%**。两份结果均为 3894 个源站、3558 个显示站，完整显示站点与线路序列化结果 SHA-256 相同：

`c5b1fb4c98a6b3b2efaaecb7d22dc8e936d72528da2c837043dd14116ceee2f2`

新增稳定回归验证：120 个重复站体应用同一规则时只执行 11 次不同文本的归一化，仍得到完整且正确的线路及换乘显示；修改规则后立即采用新结果。图层新增、移除、移动或替换即时可见，无须序列化源数据。视野外保留网格不触碰 GPU，返回视野继续复用。现有检查继续覆盖整栋模型失败回退、真实双轨、站体分离、遮罩、跨视野三角形、后台算法与完整快照。

## 浏览器采样

Chrome 无头浏览器，1280×900，SwiftShader 软件绘图，相同操作序列；统计超过 50 ms 的主线程长任务总时长，不是下载时间或单帧时间。网络、后台任务和着色器编译有波动，单次采样不能作为所有设备的提速保证。

| 操作 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 津川连续平移 | 6485 ms／53 次 | 3825 ms／32 次 |
| 交通反复开关 | 1765 ms／16 次 | 1537 ms／9 次 |
| 地形反复开关 | 5576 ms／30 次 | 2384 ms／17 次 |
| 首次开启交通 | 3293 ms／16 次 | 3332 ms／22 次 |
| 转到另一地区并加载 | 6040 ms／49 次 | 6482 ms／45 次 |

首开与跨区加载在本轮没有测到稳定提速，仍受上游瓦片、实时补充和 GPU 编译影响；已经消除测到的重复匹配、整份样式序列化及空地形帧 GPU 同步开销，不靠减少功能、精度或范围取得改善。

实际浏览器检查覆盖津川交通、全国概览、技木与大华岭附近、曦曙山和园林、地形关闭／开启、48° 透视与俯视恢复、北沪郁家桥附近及 390 像素手机布局。真实 MapLibre 图层摘要与完整序列化样式分类逐项一致，页面无 JavaScript 异常；已查看远景、近景和交通画面。在同一曦曙山位置，以相同 48° 倾角和原生 16 级缩放单独对照修改前后版本，两者均显示底图与立体模型且无页面异常；远程数据完成进度不同，因此不以两次可见要素数量判定输出一致性。

本机复核材料在未纳入发布的 `.data-update/`：`view-performance-before.json`、`view-performance-after.json`、各阶段 `.cpuprofile`、`view-performance-real-before.log`、`view-performance-real-after.log`、`view-performance-scenes.json`、`view-performance-beihu.json`、`view-performance-tilt-parity.json` 及前后对照截图。
