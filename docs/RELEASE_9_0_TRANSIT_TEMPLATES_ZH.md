# 9.0 公交站牌与轨道导视模板

发布构建：**9.0-transit-templates-v1**，2026-11-20。GitHub 提交、Cloudflare 上线与线上校验以实际发布记录为准。

## 模板与下载

“线路 → 线路显示模板”提供 53 套版式：26 种公交站牌、9 种公交车厢屏、2 种前后路牌、2 种轨道导视及 14 种轨道车厢屏。支持配色、当前站、反向预览、编组、门侧和设施图标、动态线路屏、暂停与调速、完整静态图、PNG／SVG、统一下载清单及声明式 JSON 模板导入和共享草稿。城市名称表示版式结构参考，不代表包含第三方照片、字体或商标。

公交可按选中站点的真实来源编号读取本站已登记方向，保留各线完整站序、明确分隔、真实 from/to 终点和逐班时刻／间隔资料。普通线不闭合，环线保留真实站次并均衡排在圈的两侧；同一线路分行仅显示一次大号编号。高阳详情可按范围读取实际道路背景；没有成员道路几何时明确使用站点连线。

## 轨道数据与交路

地图另选车站自动取消旧查询，先定位已读站序，再核对本站完整登记关系；两分钟完整缓存保留原始源时间。轨道完整上溯真实主关系并读取全部分期与方向，默认全线总览，复用原线路页组装与排序；不以同名或编号猜测所属关系。全线核对正式停靠与换乘，换乘使用线路自身颜色和编号。

可在具体方向上手动接入首尾真实相接的已读线路，保留完整站序，支持前接、后接、反向和撤销；共用站只显示一次。大小交路和跳停保留全线，不停靠站灰显且不点亮，下一站跳过这些站。该方案仅用于本页展示，不写入 OGF、导航或公开时刻表。

主线、折返、闭环及贯通线统一位于站点下方；灰显站圈底色不透明，不能透出底下的线。运行方向独立箭头放在第一行首站上方。图片不印底部交路说明、灰色提示和模拟文字；页面控件及 SVG 元数据保留来源与人工预览属性。缺失运营资料可按用户要求补全，真实值优先，不代表实时到站或核实运营。

## 校验与数据时间

发布前执行整包校验、更新器回归、完整快照检查与数据年龄检查。53 套模板覆盖开放／闭合、正向／反向、长线、静态与动画；浏览器检查 130 个画面及 351 个站灯像素，包含津川1号线完整27站与东南大街、熙园。实际关系样本源时间为 2026-11-20T02:32:30Z；这是已保存样本回放，不能当作本次重新联网抓取所有城市。

本次不重建全国快照、不改写其 generatedAt，不改变建筑／结构物两分钟、页面五分钟检查及三小时完整重建。复用现有共享数据和账号权限，不新增数据库结构。发布流程仍先执行既有幂等 D1 配置，再部署 Worker。
