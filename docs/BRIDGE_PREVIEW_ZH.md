## 当前规则：v4

用户于 2026-10-15 修正了旧版的长度排除与仅近景限制。当前算法为 `bridge-layer-profile-v4`：

| 条件 | 处理 |
| --- | --- |
| 正 `layer`，包括未标 `bridge`、短匝道和闭合高架 | 均参与建模；不因不足 100 米排除 |
| 同层连续、桥梁标记一致、无分岔 | 跨原始 way 拼接计长 |
| 桥长 100–350 米，两端等高且缓坡距离足够 | 平滑拱形纵断面 |
| 长桥 | 缓坡与中间平台 |
| 短段 | 缓坡面；两端不同高度时连续倾斜，不另加驼峰 |
| 引道 | 优先 100 米，尽量不少于 50 米；不足时利用实际可用道路并统一分配相邻段高度 |
| 地面分岔 | 在已有道路范围内沿所有实际分支渐降接地，最长向外寻找 100 米 |
| 相邻桥共用引道 | 分配原始区间，避免重叠；共同接点只有一个高度 |
| 层高与坡度 | 每 layer 5 米为目标表达，路网按空间平滑调整；目标约 6%，实际绝对纵坡不超过 8% |
| 上下穿越 | 在实际交叉点检查上下模型纵断面，保留至少 2.5 米估算高差；优先调整可行上下坡 |
| 上下层共用中间节点 | 两层都连续穿过时保持分层；真实终止于节点的道路仍参与坡道衔接 |
| 无数据的继续端 | 保留已知层高，不凭坐标补连接或向未知区域造路 |
| 显示与配色 | 使用原道路日夜样式；远景至少保持原线宽的可读性；放大恢复实体宽度、护栏和桥墩 |
| 原道路替换 | 只移除成功模型的真实折线区间，保留剩余道路及下穿道路；新源就绪后原子切换 |
| 真实拓扑、高程、坡度或净空无法满足 | 保留受影响相连部分的原路，不能让一处异常撤掉全城独立模型 |

这些高度是制图估算，并非实测桥型、结构或工程净空。中心线、原始节点、导航、山体高度场、建筑和水体不因建模而改写。

Worker 先规划连续道路、引道及共同接点，再同时求解高度上限、坡度和交叉高差，最后生成几何。同一算法直接用于固定样例和实际地图；地形未就绪不冒用零高程。模型与地形、建筑和植被共享深度。

原生 15、17 级切换细节：远景用较粗纵断面及轻量桥面，近景恢复细护栏和桥墩；原始道路顶点、真实连接及交叉采样保留。单批预算 8192 段、24000 个纵断面采样和 24 万三角面。等值道路对象、浮点相机变化和重复高程事件复用结果；真实数据、范围、细节层级及样式变化正确重算。拖拽期间保留显示，结束后接管；失败最多自动重试两次，也可手动重试。切换底图清理 Worker、监听、定时器和 GPU 资源。

预览计数只含高架段，排除仅用于接地的地面坡道。完整性通过原始高架 ID 和连接关系核对，不能只凭计数判断。
