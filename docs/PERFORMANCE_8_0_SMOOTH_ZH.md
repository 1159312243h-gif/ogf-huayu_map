# 8.0 渲染性能复核

本次候选：`8.0-smooth-render-v1`，2026-10-31。基于 `70009cdc1044835988349869dee3f13b1ff2f08d`，只调整绘制调度、派生索引和重复工作的复用。此文记录本地结果，不代表 GitHub 上传或 Cloudflare 部署。

## 修改及保留条件

- 地形自定义图层明确设置所需 WebGL 状态，使用随站点捆绑的 MapLibre 5.24.0 在回调后执行的状态失效、恢复机制，移除逐帧同步读取 GPU 状态。回归实际执行捆绑引擎的自定义图层绘制边界；不修改地图引擎。
- 已相交的粗批次进一步按三角形范围筛选，保留跨窗三角形及原始顺序。完整网格、顶点、高程、法线、材质、遮罩和缓存保留。索引由同一个后台模型工厂在已有几何上准备；旧式批次继续回退完整绘制。派生边界每三角形 16 字节，受既有最多 150 万顶点的网格限制，额外边界约不超过 8 MiB。
- 屋顶沿原建筑中心采样高程。重复通知没有改变高程及地形启用状态时复用现有 GPU 几何；真实高程、数据或外观变化继续重建。显隐或几何未变化时不额外安排重绘。
- 设施图层定位直接读取当前顺序和图层类型，避免复制整份实时 GeoJSON。

屋顶 19 种形状、方向、墙色／顶色、材质、零墙高、阴影、亭子、树木、交通、导航、品牌、下载及账户功能沿用现有规则。两分钟建模检查、五分钟新代检查、三小时完整重建及各数据源时间保持原样。本次没有重新抓取或改写发布快照。
