# 华域地图应用端

本批构建标识：`9.0-app-clients-v1`。源码、构建成功、已生成安装包、签名、公开下载与应用商店上架分别核验；工程存在不等于所有平台均已发版。

## 共用的功能与数据

浏览器安装版（PWA）及原生客户端都使用现有华域地图页面、地图算法和同源 HTTPS 服务。地图、屋顶及颜色、日照、交通、导航、模拟、品牌、词条、共享数据、车次、模板和自备 AI 继续使用原处理器；没有复制一套简化地图。所有客户端使用同一线上 D1，按原账号和作者／管理员权限鉴权，无需新增数据库或改变 OGF。

网页与客户端的会话存储彼此独立，各设备首次需要登录同一地图账号。私人收藏和已发布资料按原服务同步；本机 GLB、渲染偏好、未发布草稿及 AI 密钥不自动跨设备复制。密钥继续只在当前页面内存中，刷新／退出／账号切换后清除，不写入原生配置、安装包或系统钥匙串。

应用为在线客户端，首次加载、地图瓦片、查询、上传与实时更新需要网络。PWA 服务工作线程仅保存断网提示页与图标，导航失败才显示提示；不缓存账号接口、上传、模型、底图、快照或主页面，不改变两分钟建模、五分钟检查和三小时重建。不能将安装到主屏幕宣称为全量离线地图。系统后台仍遵守原页面暂停，不新增持续定位或后台模拟。

## 安装与平台工程

| 平台 | 浏览器安装版 | 原生工程及产物 |
| --- | --- | --- |
| Windows | Edge／Chrome 等支持安装的浏览器 | Electron、x64 NSIS 安装程序；可另构建 ARM64 |
| Linux | 支持安装的 Chromium 浏览器 | Electron、x64 AppImage／Deb |
| macOS | 支持安装的浏览器 | Electron、DMG；正式分发需签名与公证 |
| Android 8.0及以上 | Chrome 等支持安装的浏览器 | Java＋系统 WebView，测试 APK；正式包需维护者持有固定签名 |
| iOS／iPadOS 15及以上 | Safari 分享 → 添加到主屏幕 | Swift＋WKWebView，未签名 archive；安装分发需苹果签名及对应权限 |

站内“关于 → 安装到设备”与独立 [安装页](../site/apps.html) 调用真实浏览器安装事件。没有事件时显示平台菜单步骤，不模拟安装成功；iOS通过Safari添加主屏幕。原生包下载清单 `site/app-releases.json` 只在核实实际产物、版本、架构和 SHA-256 后添加真实 HTTPS 地址，未发布时明确为空，不填虚构下载按钮。

桌面运行时包含在安装包中；手机使用系统 WebView／WKWebView。安装包首次启动连接固定 `https://ogf-atlas.pages.dev`，保证已有 HttpOnly、Secure、SameSite 会话与同源写入规则继续有效，不放宽跨域接口。外部网站交给系统浏览器，拒绝 file/javascript 等任意协议；不提供命令执行、任意文件读取或通用原生接口。网页内容升级跟随网站，原生组件升级需重新分发安装包。原生客户端需先配套发布本批页面，才有移动文件导出适配。

## 文件与安全边界

桌面使用受沙箱保护的 Chromium，关闭 Node 集成、隔离上下文且开启 webSecurity；预加载仅暴露平台和版本，不暴露文件系统／IPC。下载限于本地图域或其 Blob，使用系统保存窗口。

移动端沿用 HTML 文件选择器上传，用户主动选择的文件继续在原表单核对。导出通过限定生产域且仅主框架可用的通信桥，将完整 Blob 分块送到应用私有临时文件；逐块计数，只有收到声明的全部字节后才打开系统文件保存窗口，取消／失败清理本次临时任务，不报告成功。不新增共享数据上传配额，实际文件、内存、磁盘与平台限制仍适用。Android 使用 Storage Access Framework，iOS 使用文件导出选择器，不申请全盘存储或持续定位权限。未知源页面和子框架不能调用保存接口。

桌面、手机、网页的文件导入与导出、图片／SVG／CSV／ZIP、账号变更、软键盘、刘海／手势安全区及横竖屏应分别实机验收；单元回归不等于所有设备完成实测。不要为了打包关闭地图功能、缩小源数据或降低既有模型细节。

## 构建

先运行 `node scripts/prepare-apps.mjs --check` 与 `node scripts/test-app-clients.mjs`。图标为仓库内确定性几何绘制，运行 `node scripts/prepare-apps.mjs` 可重新生成，共用配置为 `apps/app.json`。

桌面安装 Node.js 24 与 pnpm 11.25.0，在 `apps/desktop`：
```text
pnpm install --frozen-lockfile --ignore-scripts
node node_modules/electron/install.js
pnpm start
pnpm run dist --win nsis --x64
```
Linux用 `--linux AppImage deb --x64`；macOS用 `--mac dmg`，在对应系统构建。依赖和官方 Electron 运行时需要联网；版本锁定，不在生产机器自动升级依赖。

Android安装JDK17、Android SDK35与Gradle8.11.1：
```text
gradle -p apps/android :app:assembleDebug :app:lintDebug
```
测试 APK 使用开发签名，不作为稳定升级／商店生产包。生产签名由维护者安全保管，不能提交 keystore、密码或证书；签名变化可能需要卸载旧测试包，卸载会清除客户端本机数据。

iOS需macOS和Xcode，先在 `apps/ios` 运行 `xcodegen generate`，再打开生成工程。GitHub的未签名archive仅验证编译，不能直接装到iPhone；正式TestFlight／App Store分发由持有苹果开发者权限的维护者配置签名与审核。未接入商店发布、自动签名或支付，不会替用户注册／购买开发者服务。

`.github/workflows/app-build.yml` 提供独立多平台构建，上传Actions产物，不改D1、不更新网站、不自动发布GitHub Release或应用商店。正式下载前核对哈希、签名和实机验收。网站发布仍运行原四项检查并核实Cloudflare部署。

## 桌面本地化（9.0.1，2026-11-22）

Windows、Linux、macOS桌面工程内置完整公开前端（HTML、地图引擎、功能脚本、样式、后台计算模块、图标、已授权可选模型）及本批现有公开交通／地形／品牌／行政区快照。首次启动从本机读取程序，不等待线上脚本逐个下载；安装包因此会增大。并未附带全球完整底图瓦片、全部建筑或任意地区离线查询，不宣称全量离线地图，也不改变算法或降低细节。Android及iOS主屏幕版本轮维持原加载方式。

桌面通过隔离会话为固定生产HTTPS域返回已校验本地资源，页面地址、Cookie、Origin、Worker、同源写入与原作者／管理员权限不变；所有/api/*、登录、投稿、上传、自备AI及第三方底图请求仍沿原网络服务。不会启动本地无鉴权写入服务、不将私人接口存入公开缓存，也不更改已有账号数据。浏览器安装线程与手机客户端规则保持原样。

程序清单desktop-assets.json记录每个文件的SHA-256和字节数。启动先选择一份完整本地版本；启动后及前台每五分钟检查线上程序清单，三路下载并逐文件校验，全部完成才原子更新版本指针，下一次重新启动应用生效。当前窗口不混用两代脚本；未知运行时、不完整文件、连接重置及校验失败保留当前程序。主程序及Electron运行环境仍需下载安装新版安装包。此清单校验以固定本站HTTPS为信任来源，不冒充独立发布者签名。

公开快照优先复用本机完整缓存或安装包内原快照，并按五分钟限频后台核对；显式强制刷新走网络。缓存保存原始字节及源数据时间，下载时间只作本机维护时间。地形分包和材质仍按原代际、完整几何与正式处理器校验后接管，失败保留已显示完整数据。私有API不增加此缓存，建筑和结构物仍用原两分钟缓存，全国重建仍由三小时工作流执行。专用公开传输缓存预算384 MiB；它不修改用户上传配额或删除原模型／账号存储。首次未访问的底图瓦片、即时查询及账号服务仍需联网。

准备资源：node scripts/prepare-desktop.mjs --bundle；验证清单：node scripts/prepare-desktop.mjs --check。原生构建的predist和presmoke自动准备，发布清单更新自动同步线上资源清单。生成的apps/desktop/renderer/仅为忽略的构建目录，不再向Git提交整份站点副本。回归见scripts/test-desktop-local.mjs；真实Electron离线启动通过pnpm run smoke验收，不能以工程或单元测试代替实际安装包检查。

固定OGF公开底图域的匿名瓦片、字体及图标按需保存，专用预算192 MiB／4096条，单项8 MiB只限制是否缓存、不截断原网络响应。有效期取不超过五分钟及上游更短期限，命中不续期；过期先联网核对，临时失败可显示已访问旧瓦片，取消及永久HTTP错误不冒充成功。缓存不含查询参数、私人API、登录、上传或搜索，缺少官方源时间仍标为未知，不能把本机保存时间称为地物更新。它与384 MiB公开快照预算分开，已有模型／用户存储不清理。

2026-11-23补充验收：压缩文件在HTTP自动解压后仍按解压字节数与SHA-256核对完整内容，源时间不回退；磁盘不可写时仍返回完整核验后的网络数据。三小时交通／地形和目录工作流同步提交desktop-assets.json，避免新数据与本地下载清单不同步。

线上桌面哈希清单暂不可用时，仍允许原网络数据进入既有前端完整性处理器，不将其存成已核验的持久快照；已有磁盘完整快照保留。Android／iOS工程版本号同步9.0.1仅供后续构建，手机加载架构本轮未本地化。

9.0.2修正更新清单缺失或本机磁盘不可写的普通自动刷新：检测到不能保存新快照后，后续按原频率的读取直接交付在线响应，由既有前端核验；网络失败仍返回原完整快照。不把共享用户资料静态打包，用户资料仍保存线上D1并在原入口查询。上传的数据包需用户选中并生成专题图；补充属性展示于详情与共享搜索，不自动修改OGF底图或模型。9.0.1本地交付保留，9.0.2另行生成新包。


## 全平台优化9.0.3（2026-11-23）

此节更新前述仅桌面本地化及主屏幕仅提示页的限制。Windows／Linux／macOS统一使用完整安装资源、公开快照和校验后更新；所有桌面构建增加实际离线启动检查。Android安装包同样内置程序和公开快照，保持生产HTTPS同源与现有账号、文件导出；前台/后台按WebView生命周期暂停恢复。iOS／iPadOS继续Safari主屏幕版，首次联网由ServiceWorker在后台准备完整程序；全部资源SHA-256一致后启用，失败保留旧代，已打开窗口不热替换。Safari可能清理浏览器存储；未准备成功不能称离线可用。iOS原生工程仅补内容进程恢复，分发仍需苹果签名。

公开数据普通到期读取直接交付完整新响应，保留原始日期及前端代际核验，不用“后台取到了”冒充已接管；没有发布清单仍允许原在线数据路径，拒绝把未经哈希核验的响应写入快照。共享简介、属性、数据包、logo、班次、上传、登录及/api/*完全绕过安装缓存，继续线上D1按原入口读取；不会因内置旧数据隐藏用户新发布内容，也不自动把数据包铺进底图。所有更新仍受网络及上游同步影响。

生成Android资源用node scripts/prepare-desktop.mjs --mobile，桌面用--bundle，构建目录忽略且不提交二进制；三小时工作流同步desktop-assets.json与app-cache-version.js。程序缓存标识由实际代码内容确定，数据更新不重装完整程序。公开浏览器传输缓存192MiB，不清理用户／模型存储，存储不可用继续联网。所有脚本采用defer并行下载，保留既有执行顺序、模块和功能。回归scripts/test-app-cache.mjs与原应用、帮助、助手、完整地图检查。

Linux离线启动CI在临时执行器中按Electron要求为下载的chrome-sandbox设置root属主及4755权限，不使用--no-sandbox、不开关用户系统安全策略；发行包仍保留沙箱。不同Linux发行版的AppImage执行及命名空间限制需用户设备实测，另提供Deb安装包。
