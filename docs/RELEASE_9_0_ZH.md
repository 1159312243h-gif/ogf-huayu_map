# 华域地图 9.0

发布构建：`9.0-shared-data-v1`，包版本：`9.0.0`，日期：2026-11-17。线上入口：[华域地图](https://ogf-atlas.pages.dev/?release=9.0-shared-data-v1)。是否已部署以 GitHub Actions 和实际线上版本为准。

## 本次功能

- 共享词条：按原始要素类型与编号添加多人简介、来源、建筑名称及自定义属性，公开查询；作者管理自己的内容，管理员管理全部并保留作者。原始 OGF 和共享属性分别展示。
- 共享数据：独立“数据”入口公开 CSV／JSON／GeoJSON，支持单要素至国家等范围的 POI、人口、GDP、地价、通行需求、车次资料，保留来源、口径、单位、日期、许可和版本。
- 专题图：服务端字段统计，数值分位数／比例点和类别图，俯视及倾斜使用同一几何，SVG／PNG 导出及统一下载清单；缺值和缺位置分别说明。
- 取消共享数据包的应用层容量、记录、列、顶点、包数和频率配额；实际处理受托管平台与设备资源约束，失败不截断数据或发布半包。
- 帮助更新为9组可搜索说明，共享词条与共享数据独立分组；README 同步入口、格式、权限、下载与实际处理能力。

上传数据目前接入标准化、统计和专题制图，尚不自动校准交通模拟或替换真实时刻表。私人收藏、贴图和本机模型仍按既有规则隔离。屋顶、颜色、光影、交通、导航、原更新周期不因升级改变；不重写源数据抓取时间。

## 验收与部署

发布前执行 `npm run verify`、`npm run test:data-update`、`npm run data:update:check`、`npm run check:data`，并核对共享词条和数据上传／下载、权限、专题俯视／倾斜及手机布局。Node 脚本与这些 npm 入口等价。完整发布包通过既有脚本保留本地，避免将整站副本再次写入 Git 历史。

生产部署先应用 `0002_feature_contributions.sql`、`0003_feature_properties.sql`、`0004_shared_datasets.sql` 等幂等迁移，保留既有账号及个人数据；继续使用既有 D1，无新增付费服务。随后 GitHub Actions 按 `--no-bundle` 发布 Pages Worker，核对版本、静态文件及共享接口。详情见[共享数据说明](SHARED_DATASETS_ZH.md)和[用户确认规则](MAP_RULES_ZH.md)。
