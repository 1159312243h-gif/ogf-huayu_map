# 品牌管理者

发布构建 `9.0-brand-management-v1`（2026-11-18）。GitHub 提交、数据库迁移、Cloudflare 部署及线上核验状态以实际发布记录为准。

## 用户与管理员流程

在品牌详情选择“品牌资料 / 申请管理”，或在品牌页展开“品牌资料与管理者申请”，输入完整品牌名并点击“查看品牌资料”。登录后填写申请说明、可选的依据链接并提交。首位通常自动通过；已有其他待审申请或管理者时，后续申请等待站点管理员审核。已知内置品牌的明确别名归入同一品牌，同品牌同账号保留一份申请及完整处理历史，并发首申只自动批准一人。

获批者维护对应品牌的公开简介、官网及 logo；保留原 logo 作者。没有其他品牌、运营者、轨道系统或全站账号的管理权限，也不会修改 OGF 原始标签。品牌管理者表示本站维护权限，不代表官方认证。仍可由原作者维护其自己的其他标识。

“我的申请”可查看状态、处理记录或撤回待审申请。管理员从“账号 → 查看品牌管理申请（含自动通过）”或品牌页管理员范围查看所有申请，包含自动通过、待审核和已处理项，显示申请人、品牌、说明、依据、时间和处理来源。列表支持状态筛选及每页20条翻页。这是站内申请记录，不发送外部邮件或消息。

管理员可以批准、驳回、撤销权限、禁止用户管理该品牌或解除禁止。驳回和禁止必须填写原因。禁止会同时撤销对应品牌授权、阻止再次申请和任何该品牌 logo 写入，即使用户是原上传者也不能绕过。解除禁止后状态为已撤销，需重新申请，不自动恢复权限。其他品牌和站点账号不因此停用。管理员可批准同品牌的多名管理者。

## 隐私、刷新与失败

管理者昵称、品牌简介与官网公开；申请说明、依据、审核原因与历史仅本人及站点管理员可读，不作为公开导出或助手查询结果。所有文字以文本显示，资料链接只接受不带凭据的 HTTP／HTTPS。退出或换账号清除私有草稿与授权；旧响应不能覆盖新账号。原表单保存校验 revision，权限在最终数据库写入时再次校验，撤权后的旧表单也会失败。

品牌页可见且管理区展开时，每两分钟检查申请与授权；可手动刷新。收起、离页和后台暂停，不轮询所有品牌。接口不可用时明确提示，现有地图及内置标识继续工作。当前实现不自动回滚不合规者过去公开的资料，管理员可自行编辑品牌资料和删除或修正 logo。

助手提供 get_brand_profile 读取公开资料和 prepare_brand_management 准备申请草稿。须先登录，已有草稿会拒绝覆盖；取消、账号改变和迟到结果受到保护。由用户在原表单核对后提交，助手不能自动审批、撤权或发布。

## 数据库及接口

复用既有 D1，按顺序应用 `migrations/0001` 至 `0006`，不增加 R2 要求。`0006_brand_management.sql` 幂等创建申请、授权、禁止、公开资料、历史五表。申请决策、关联授权和历史写入在一个 D1 batch 事务中完成，版本冲突或失败整体回滚。删除账号清理所属申请、授权及禁止；公开品牌简介保留并清空已删除编辑者。

| 接口 | 用途及权限 |
| --- | --- |
| GET /api/brand-management/brand?name=完整名称 | 公开资料与管理者；登录者额外获取自己状态 |
| PATCH /api/brand-management/brand | 对应品牌管理者／管理员保存简介与官网，带 revision |
| GET /api/brand-management/session | 当前用户授权及禁止范围 |
| GET /api/brand-management/applications?scope=mine或admin&status=all&offset=0 | 本人申请或管理员全部申请，每页20条 |
| POST /api/brand-management/applications | 登录者提交说明与依据，重新申请携带旧 revision |
| PATCH /api/brand-management/applications/:id | 管理员处理或本人撤回，带 action、revision、note |
| GET /api/brand-management/applications/:id/events | 本人或管理员查看处理历史 |

申请说明最多2000字，公开简介最多5000字；品牌名最多160字，链接最多2048字，处理原因最多1000字。以上是表单字段边界，不改变共享结构化数据包规则。

维护入口为 site/brand-management-server.js 与 site/brand-management.js。运行 `npm run brand-management:sync` 同步 Worker，`npm run test:brand-management` 验证并发、事务、权限、隐私和迁移；`npm run test:map-agent` 验证真实助手处理器与公开返回。整包 verify 纳入上述检查。仅本地完成不表示已经发布。
